# 蓝桥研习室

中文个人备赛网站：2026-11-09 至 2027-02-28，16周课程、112天学习清单、48道Python练习、知识树、自测、笔记与错题记录。

本站所有执行资源已放在assets/vendor中，不需要外部CDN或后端。Python使用CodeMirror与Pyodide，在浏览器Web Worker执行；它不替代比赛指定的PaddlePaddle/FAISS环境。学习记录只保存在当前浏览器。

本仓库为GitHub Pages静态发布目录，页面入口为index.html。导航使用hash，资源全部采用相对路径，支持项目子目录部署。

本地预览：在本目录运行 `python -m http.server 4173`，打开 `http://localhost:4173/`。不要直接双击index.html。

公开练习是学习工具，不能视为官方隐藏评分。规则PDF由用户提供；站内模拟题与教学资料为自建训练内容。运行时与编辑器许可证随assets/vendor提供。
